# py3-notifier

A py3status module to work with 
[i3-notifier](https://www.github.com/sencer/i3-notifier).

> [!NOTE]
> **System Dependency**: This module requires `PyGObject` (Gio) which depends on system libraries. Please install `python3-gi` (or equivalent for your distribution) via your system package manager before installing via pip.

    pip install py3notifier
